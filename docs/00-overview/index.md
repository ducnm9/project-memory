# Project Memory Cloud / Engineering Intelligence Platform

## Document Set v2

This document set defines the product, architecture, domain/data model, ingestion, retrieval, MCP interface, governance, security, evaluation, and implementation backlog.

## Core thesis

> RAG is the search engine of Project Memory, not Project Memory itself.

> Learn once. Record once. Retrieve everywhere.

Project Memory turns a repository and its engineering ecosystem into a living, evidence-backed memory that developers and AI agents can query, enrich, and govern.
