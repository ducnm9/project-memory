# Glossary

- **Project Memory** — canonical, evolving memory of an engineering project.
- **Knowledge Item** — semantic unit such as Decision, Concept, Architecture or Investigation.
- **Source** — external artifact from which knowledge is derived.
- **Evidence** — material supporting a knowledge claim.
- **Fact** — project assertion represented as a structured fact.
- **Relation** — explicit connection between knowledge entities.
- **Proposal** — candidate knowledge awaiting validation/approval.
- **Freshness** — likelihood that knowledge remains valid.
- **Knowledge Gap** — recurring question for which supported knowledge is missing.
- **MCP** — agent-facing Model Context Protocol interface.
