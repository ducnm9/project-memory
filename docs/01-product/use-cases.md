# Use Cases

## Developer
- onboarding and project overview;
- architecture discovery;
- "why" questions;
- troubleshooting;
- impact analysis before changes.

## AI Agent
- resolve project;
- retrieve relevant context;
- explain code;
- reuse previous investigations;
- propose newly discovered knowledge.

## Tech Lead / Architect
- review decisions;
- detect stale/conflicting knowledge;
- inspect project evolution;
- identify knowledge gaps.

## Platform Admin
- manage projects, connectors, permissions and audit.
