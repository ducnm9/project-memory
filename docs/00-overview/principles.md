# Design Principles

1. Knowledge is richer than documents.
2. Repository code is a first-class source.
3. No README/Markdown prerequisite.
4. RAG is retrieval infrastructure, not the knowledge model.
5. Search before create/update.
6. Agents propose; humans govern important canonical knowledge.
7. Evidence and provenance are first-class.
8. Project scope and authorization are mandatory.
9. Knowledge is versioned and auditable.
10. Freshness influences retrieval.
11. Storage technology remains replaceable behind the API/MCP boundary.
12. The platform dogfoods its own memory model.
