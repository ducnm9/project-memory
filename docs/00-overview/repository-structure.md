# Repository Structure

```text
project-memory/
├── README.md
├── docs/          # Human-readable documentation
├── specs/         # Machine-readable contracts
├── examples/      # Concrete knowledge and MCP examples
├── diagrams/      # Mermaid architecture diagrams
├── evaluation/    # Retrieval/answer/governance benchmarks
├── scripts/       # Developer utilities
└── .github/       # PR/Issue templates and CI
```

Keep `docs/` explanatory and `specs/` authoritative for machine validation.
