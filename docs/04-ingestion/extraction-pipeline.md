# Extraction Pipeline

```text
Source
  ↓
Normalize
  ↓
Parse / Analyze
  ↓
Extract claims/entities
  ↓
Infer candidate relations
  ↓
Duplicate / conflict checks
  ↓
Proposal
  ↓
Validation / Review
  ↓
Publish
```

Preserve source locations wherever possible so knowledge can be inspected and verified.
